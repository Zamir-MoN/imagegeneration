Image Generation REST API

Integrate this image generator into any backend, script, or external service by sending an HTTP POST request to http://localhost:5000/api/generate.

cURL Request Example

curl -X POST http://localhost:5000/api/generate \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Modern luxury dental clinic with soft ambient lighting and clean glass equipment",
    "style": "Commercial Photography",
    "aspectRatio": "16:9"
  }'

JavaScript (fetch) Example

const response = await fetch('http://localhost:5000/api/generate', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    prompt: 'A smiling person receiving expert dental checkup',
    style: 'Commercial Photography',
    aspectRatio: '16:9'
  })
});
const data = await response.json();
console.log('Image URL:', data.image.url);
