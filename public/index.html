Image Generation & Dump REST API

Integrate this image generator and curation workflow into any backend, script, or external service.

1. Generate Image (POST /api/generate)

curl -X POST http://localhost:5000/api/generate \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Modern luxury dental clinic with soft ambient lighting and clean glass equipment",
    "style": "Commercial Photography",
    "aspectRatio": "16:9"
  }'

2. Curate Status (PATCH /api/images/:id/status)

curl -X PATCH http://localhost:5000/api/images/img_12345/status \
  -H "Content-Type: application/json" \
  -d '{ "status": "approved" }'   # or "rejected", "pending"

3. Query Filtered Dump (GET /api/images?status=approved)

curl http://localhost:5000/api/images?status=approved
